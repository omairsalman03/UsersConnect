## What the AGPL means if you run UsersConnect

- **Running it unmodified** (for yourself, your family, a club, an organization): nothing extra to do.
- **Modifying it and letting others use your modified version over a network** (for example, running it as a public or shared instance): you must offer those users the source code of your modified version, under the same license. This is the difference between the AGPL and the ordinary GPL: it covers software people use over a network, not just software you distribute.
- **Private modifications that only you use** don't require you to publish anything.

This is a plain-language summary, not legal advice. The license text is authoritative.
